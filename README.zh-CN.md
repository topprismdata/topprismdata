## 为什么是 TopPrism

AI 系统正在越来越多地基于企业知识工作。找到相关文档还不够：系统还需要知道陈述来自哪里、是否仍然有效、与其他实体如何关联，以及哪些部分仍然不确定。

TopPrism 把知识视为连接企业现实与 AI 智能体之间、可治理且持续演进的一层：

```text
企业现实 → 证据 → 受治理知识 → 智能体上下文 → 决策或行动
```

因此，主页中的每个仓库都会标注用途、成熟度和证据类型，避免把技术工作误读为客户部署或商业成果。

## 证据标准

每个 TopPrism 原创仓库都区分三个维度：

| 维度 | 回答的问题 |
| --- | --- |
| Purpose / 用途 | 这项工作要解决哪类问题？ |
| Maturity / 成熟度 | 它是研究、框架、应用引擎、工具还是参考实现？ |
| Evidence / 证据 | 当前描述由哪类数据、评测或运营基础支持？ |

这样，匿名化运营研究不会被误读为生产部署，内部评测不会被误读为外部基准，上游 Fork 也不会被误读为 TopPrism 原创能力。
